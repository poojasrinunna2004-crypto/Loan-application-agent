POST/applications

Create a draft

Creates a draft only. Amount must be greater than $0 and at most $2,000,000; term must be 1 to 480 months.

Returns 201 Created. An unknown customer returns 404. 

{
  "customer_id": 1,
  "loan_type": "personal",
  "amount": 12000,
  "term_months": 36,
  "purpose": "Home repairs"
}
GET/applications/{application_id}

Review an application

Returns the saved application and its current status. This request never submits it.

POST/applications/{application_id}/submit

Submit after confirmation

Changes a draft to submitted only after the user has reviewed it and explicitly confirmed.

Missing or false confirmation returns 400. No bank is contacted.

{
  "confirmation": true
}
!

Mock environment only. The API uses fictional sample data and a local SQLite database. It does not connect to a bank or submit real applications.
